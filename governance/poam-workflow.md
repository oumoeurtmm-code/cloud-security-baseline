# POA&M Workflow

Plan of Action and Milestones (POA&M) management documents known weaknesses, planned remediation actions, ownership, and target completion dates.

## Workflow

1. Identify finding or weakness
2. Assign severity and business impact
3. Record affected asset, system, or control
4. Define remediation action
5. Assign owner
6. Set target completion date
7. Track status through closure
8. Retain evidence of remediation

## Suggested POA&M Fields

| Field | Description |
|---|---|
| ID | Unique tracking identifier |
| Finding Source | Scan, audit, review, manual discovery |
| Affected Asset | System, account, application, or service |
| Control Reference | NIST / policy / internal standard |
| Severity | Low / Moderate / High / Critical |
| Planned Action | Specific remediation step |
| Owner | Responsible team or individual |
| Due Date | Target completion |
| Status | Open / In Progress / Closed |
| Closure Evidence | Proof of remediation |

## Severity Definitions

| Severity | Definition |
|---|---|
| Critical | Immediate exploitation risk or active finding — remediate within 15 days |
| High | Significant exposure — remediate within 30 days |
| Moderate | Limited exposure — remediate within 90 days |
| Low | Minimal risk — remediate within 180 days or accept with documented justification |

## Notes

POA&M tracking is most useful when linked directly to control mapping, continuous monitoring, and documented remediation evidence.
